Mise en place

  1. Outlook : Fichier › Options › Courrier › Signatures › Nouvelle, puis coller (Ctrl+V) dans la zone de texte.
  2. Gmail : Paramètres › Voir tous les paramètres › Signature › Créer, puis coller.
  3. Outlook (fichier) : cliquer sur « Télécharger (.htm) », puis enregistrer le fichier dans C:\Users\"utilisateur"\AppData\Roaming\Microsoft\Signatures (remplacer « utilisateur » par le nom de session Windows ; le dossier AppData est masqué, il suffit de coller le chemin dans la barre d'adresse de l'Explorateur). Redémarrer Outlook : la signature apparaît dans la liste. Valable pour Outlook classique uniquement.
  4. Apple Mail / autre : coller dans l'éditeur de signature, ou utiliser « Afficher le code HTML » si la messagerie accepte le HTML brut.
