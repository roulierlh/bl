Mise en place

  1. Outlook : Fichier › Options › Courrier › Signatures › Nouvelle, puis coller (Ctrl+V) dans la zone de texte.
  2. Gmail : Paramètres › Voir tous les paramètres › Signature › Créer, puis coller.
  3. Apple Mail / autre : coller dans l'éditeur de signature, ou utiliser « Afficher le code HTML » si la messagerie accepte le HTML brut.
